# Project Brief

DevCodex is a free, installable learning app for software engineering topics, principles and concepts. It targets iPhone, Mac, Android and desktop browsers from one SvelteKit codebase deployed as a static PWA on GitHub Pages (`Tonys-Coding/DevCodex`, base path `/DevCodex`). No App Store builds and no required purchases.

## Four sections

1. **Learn**: an interactive article library in a ByteByteGo-like teaching style (visual diagrams you can step through, inline checks). All content is original.
2. **Shorts**: a TikTok-style vertical feed of animated concept explainers, "spot the bug" snippets, trade-off questions and myth-vs-fact cards. No video at launch; each short links to its article.
3. **Trivia**: a swipeable deck of concept cards. The deck grows as the learner finishes articles (each article unlocks its cards).
4. **Practice**: a smaller LeetCode/NeetCode-style practice area where you write and run code in the browser, in Python (Pyodide) and JavaScript (Web Worker). Problems are written in our own words and link out to the original problem page.

## Delivery phases

- Phase 0: tooling, memory bank, a working scaffold.
- Phase 1: three coded prototypes (desktop and phone). The user picks one, a combination, or asks for revisions.
- Phase 2: the full app in the approved direction.
