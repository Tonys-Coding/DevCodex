# Product Context

## Purpose and audience

DevCodex helps beginner-to-intermediate software engineers understand and remember concepts through interactive lessons, short visual explainers, trivia and coding practice. It runs on iPhone, Android, Mac and desktop browsers.

## Core learning loop

1. Read and interact with an original lesson (step-through diagrams, inline checks).
2. Finish the article. This unlocks its concept cards in the Trivia deck.
3. Review the cards and shorts. Related cards point to deeper articles.
4. Practice algorithm problems in the Practice section, a separate and smaller loop.

## Content scope for the first release

- Web foundations
- Programming concepts
- Data structures
- About 12 practice problems: arrays/hashing, two pointers, sliding window and stack

## User preferences (carried over from the earlier session)

- Readability on phones is a priority.
- A darker, low-glare overall theme is preferred.
- Wants a distinctive look, not a generic one.
- Wants to see Svelte's full capabilities.
