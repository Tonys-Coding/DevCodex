# Visual prototype prompts

These boards were generated with the built-in image tool. They are design references; wording and details must be rebuilt in Svelte.

## A — Field Guide

> Create a polished wide landscape design board with two views side by side: a realistic desktop browser layout taking about 65% of width and a realistic phone-width mobile web app layout taking about 35%. The same DevCodex learning product in both. Direction: Field Guide. A calm editorial learning interface inspired by a beautifully typeset field guide, warm cream paper, dark ink, restrained burnt orange and sage accents. Desktop: slim left chapter navigation, generous narrow reading column, right marginal notes with one crisp original client-server diagram. Mobile: top wordmark, visible lesson title “How the web works,” readable body text, one diagram and large Next step button; bottom navigation with Learn, Cards, Trivia. Show a learning article with a simple interactive stepper state, not a marketing landing page. Use editorial serif headings and clean sans body at comfortably readable size, strong contrast, generous line height, no tiny gray text, no generic dashboard cards, no floating device hardware frame. Straight-on UI screenshot aesthetic, pixel-sharp, no perspective, no hands, no watermarks. Make desktop and mobile compositions visibly responsive rather than merely scaled.

## B — Learning Studio

> Create a polished wide landscape board with two straight-on app views side by side: desktop browser web app at about 65% width and responsive phone-width web app at 35%. Same product content adapted, not simply scaled. Direction: Learning Studio. A focused learning workspace for a beginner studying software engineering. Deep dark teal background, warm ivory type, luminous mint accents and restrained amber for progress, high contrast. Desktop: narrow module navigation rail, large central interactive skill map with clean connected nodes labeled Web, HTTP, APIs, Data, and a substantial selected lesson workspace titled “How the web works” with a client-to-server request/response diagram and large “Reveal next step” control. Phone: compact top bar, single-column lesson surface with the same diagram, legible reveal, and bottom nav Learn, Cards, Trivia. Strong type and accessible body size, hierarchy from lines and space rather than nested cards or generic widgets. No terminal clichés, perspective, hands, hardware bezel, or watermarks. Make it feel implementable in Svelte.

## C — Signal

> Make a pixel-sharp wide landscape board with a responsive desktop web app view on the left taking about 65% width and a phone-width mobile web app view on the right taking about 35%. No device hardware, straight-on screenshots. Direction: Signal. A beginner software-engineering learning app whose short-form feed uses swipeable visual explainers and trivia, not videos. Bright off-white background, near-black text, electric blue and coral blocks, readable modern grotesk typography, bold but restrained. Desktop: spacious feed-first layout with simple left navigation, central large visual concept card titled “What happens when you open a website?” showing a clean browser-to-server diagram, right “Learn deeper” column with a related article and skill progression. Mobile: one vertically swipable concept panel at a time, the same diagram and short explanation, large thumb-friendly “Next card” button, bottom nav Learn, Feed, Trivia, and small progress indicator. Show a trivia prompt “Who sends the request?” with Browser and Server choices. Avoid social-media chrome, video imagery, tiny gray text, nested cards, and KPI dashboards. Make it feel implementable in Svelte and comfortable for mobile reading.
