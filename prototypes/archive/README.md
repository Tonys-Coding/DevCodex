# DevCodex prototype boards

These images show three possible desktop and phone experiences. They are generated visual mockups, not screenshots of working Svelte screens.

| Direction | Emphasis | Tradeoff |
| --- | --- | --- |
| [A — Field Guide](field-guide.png) | Calm, readable lessons | Slower to scan |
| [B — Learning Studio](learning-studio.png) | Connected skill map and focused lesson | Denser first impression |
| [C — Signal](signal.png) | Fast visual concept feed | Less room for long explanations |

Each direction uses the same beginner topic, “How the web works,” so the choice can focus on hierarchy and reading comfort. Generated text is illustrative and may contain small errors; the selected design will be rebuilt with real Svelte components and original copy.

The images were made with the built-in image generation tool. Prompts specified a paired desktop and 390px phone layout, high contrast text, a client/server diagram, an interactive-looking learning control, and each direction's palette and hierarchy. No existing app screens or third-party lesson assets were used as image inputs.
