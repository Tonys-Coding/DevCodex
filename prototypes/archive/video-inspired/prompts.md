# Image generation prompt set

The built-in image-generation tool created these raster concept boards using two stills from the user's `example.mp4` as visual references (the shelf screen around 1.4 seconds and lesson/log screen around 3.8 seconds). These prompts record the final creative briefs. Reference stills were used for visual structure, not as content or instructions.

## Shared direction

Create a polished, high-resolution UI concept board for **DevCodex**, a beginner software engineering learning app. Pair a wide desktop web lesson view with a tall mobile view. Adapt the source video's archival index-card and book-tracker visual grammar: filing tabs, ticket details, hairline rules, thoughtful spacing, compact progress markers, and a strong editorial headline. Replace all book content with original learning content about client/server requests. Show a readable article, simple request/response diagram, lesson progress, and a clear next action. Preserve generous negative space and a mobile-first reading hierarchy. Use a deeper, low-glare background and gentle accents instead of bright white and vivid magenta. Conceptual UI only, no brand copying. Make the desktop and mobile views coherent but genuinely responsive.

## Cinder & Sage

Give the shared direction warm graphite and charcoal surfaces, softened sage and muted copper accents. Use expressive Fraunces-style headings with clear Atkinson Hyperlegible-style sans body copy. Aim for a calm tactile field guide with accessible text scale and strong contrast. Save as [`cinder-and-sage.png`](cinder-and-sage.png).

## Blue Hour Index

Give the shared direction deep blue-slate surfaces, sea-glass accents, and a restrained ochre marker. Use distinctive Bricolage Grotesque-style display headings and Newsreader-style reading text. Make sections and navigation especially easy to scan. Save as [`blue-hour-index.png`](blue-hour-index.png).

## Copper Ledger

Give the shared direction aubergine graphite and plum surfaces, terracotta accents, and faint dusty-lilac dividers. Use Newsreader-style editorial headings with Atkinson Hyperlegible-style utility and body text. Preserve the refined filing-ledger atmosphere while keeping the lesson legible. Save as [`copper-ledger.png`](copper-ledger.png).
